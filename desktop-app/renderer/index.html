What is this? (Don't have a backend?)

A trackable QR encodes a short redirect link instead of the final destination. When someone scans it, your server logs the visit and forwards them to the real page — so you can see how many times it was scanned.

Backend URL is the address of that server (e.g. https://qr.yourdomain.com). API key is a secret the app sends to create codes; you set it on the server and paste the same value here.

You don't need to buy anything. Kuiqr ships with a free, self-hosted backend you can run on this Mac with one click (button below). Or point it at your own server / a compatible service.
